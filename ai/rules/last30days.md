## When / when not
- When: the owner asks what people say now about a topic, product, person, company or market: recent reactions, sentiment, trends, "what is new with X", competitor chatter, with sources from the last 30 days. Typed `/last30days <topic>` always.
- Not: library or API docs (context7), code search in a repo (Map, graph, Serena, rg), one known URL (WebFetch), SEO of a site (claude-seo), facts that do not change month to month, private or internal data.
- Ask first: the setup wizard asks in chat before it reads browser cookies (X and other logged-in sources) and it installs free CLIs (yt-dlp, Digg, arXiv, Techmeme, Yahoo Finance). Paid keys (ScrapeCreators credits, xAI, OpenAI, Perplexity, Brave, Apify) cost money. Publishing a brief library to `ht-ml.app` makes it public. Never add a key, run the wizard, allow cookie reads or publish without the owner.
- The topic text goes to outside services (Setup checklist, item 6). Do not research a private person or anything secret.
- Codex, opencode and Hermes: not installed for them (Claude only).

## Enforcement
- L0: one short line in `ai/agents-md/90-toolbox-and-vendor-rules.md` (passive context): last30days for "what people say in the last 30 days", typed `/last30days <topic>`.
- No routing row: the plugin skill description and the typed slash command are enough; a prompt regex for "recent", "trend" or "what people say" fires on unrelated prompts.
- The tool enforces its own output contract (the LAWs and the pre-present self-check in SKILL.md) and its first-run consent flow.
- Session cost: v3.39.0 has NO SessionStart hook (vendor CHANGELOG, "Removed": "The Claude Code and Grok plugin no longer installs a SessionStart hook. Welcome, source status, and the ScrapeCreators tip run only when `/last30days` is invoked"). The cost per session is the skill description in the listing (about 70 tokens). Older releases (seen: 3.3.1 on the M3 Mac, read at v3.9.4) had `hooks/scripts/check-config.sh` on SessionStart: it printed a welcome of 5 to 6 lines (about 100 tokens) in every session until set up, then a 2 to 5 line status, never silent; no network; it created `~/Documents/Last30Days` and set the env files to mode 600. install.sh moves the plugin to the newest stable tag, so that hook goes away with the update.

## Setup checklist
1. Install (every OS, install.sh on every run, Claude only): newest stable tag from `LAST30DAYS_SOURCE`, the tree at that commit audited with `agent-audit dir` (accept lines per full commit), then `claude plugin marketplace add mvanhorn/last30days-skill#<tag>` and `claude plugin install last30days@last30days-skill` (user scope), the marketplace clone checked against the commit of the tag. A marketplace `last30days-skill` from another source (for example the vendor's README route without a tag) is replaced; the plugin is uninstalled with `--keep-data` first, and uninstall.sh restores the old source.
2. On by default: install.sh writes `"last30days@last30days-skill": true` in `enabledPlugins` of `~/.claude/settings.json` (recorded), only after the plugin step succeeded. That happens on the first run of this setup (stamp `~/.local/state/ai/last30days.on-once`); later runs keep a false that you set. Off for one project: `"enabledPlugins": {"last30days@last30days-skill": false}` in that project's `.claude/settings.json`.
3. Auto-update: off (third-party marketplace default). Do not add the vendor's `npx skills add` route on top: one copy only. The skill's stale-clone check reads Claude's normal plugin cache; that is expected.
4. Prerequisites: Python 3.12 or newer for the engine (the runtime preflight checks it and stops with install guidance otherwise), node. Optional: `yt-dlp` for YouTube.
5. Keys: none required. Reddit (public JSON), Hacker News and Polymarket work without keys. Optional, through the vendor wizard (`/last30days` once; it asks in chat) or in `~/.config/last30days/.env` (mode 600): `SCRAPECREATORS_API_KEY` (TikTok, Instagram, Reddit backfill; 10,000 free calls), `X_BEARER_TOKEN` or X cookies `AUTH_TOKEN` and `CT0` or `XAI_API_KEY`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, `PERPLEXITY_API_KEY`, `PARALLEL_API_KEY`, `BRAVE_API_KEY`, `APIFY_API_TOKEN`, `BSKY_HANDLE` and `BSKY_APP_PASSWORD`, `TRUTHSOCIAL_TOKEN`. Keys may also live in the macOS Keychain (`last30days-<KEY>`). Never put them in `~/.config/ai/secrets.env` or in a repo.
6. What leaves the machine (vendor "Security & Permissions", v3.39.0): the topic and planned queries go to Reddit (reddit.com), Hacker News (hn.algolia.com), Polymarket (gamma-api.polymarket.com), YouTube (yt-dlp, local), GitHub, Wikidata (a company or person name), USPTO patent search (company runs); with keys or consent also ScrapeCreators, the X API (api.x.com), xAI, Xquik, OpenAI, OpenRouter, Perplexity, Parallel AI, Brave, Bluesky; Yahoo Finance through `yahoo-finance-pp-cli` when installed; `ht-ml.app` only after an explicit publish opt-in (public unless password protected). With `LAST30DAYS_API_KEY` and `LAST30DAYS_API_BASE` set, research goes to that remote API instead. Telemetry: none found in the engine (code read at v3.9.4; UNVERIFIED for v3.39.0 and the vendored code).
7. Configure once (optional): run `/last30days` in Claude and finish or skip the wizard; "Skip for now" writes `SETUP_COMPLETE=true` and `BROWSER_CONSENT=false` to `~/.config/last30days/.env` (mode 600), so the wizard does not come back and no browser is read. By hand: `mkdir -p ~/.config/last30days && printf 'SETUP_COMPLETE=true\nBROWSER_CONSENT=false\n' > ~/.config/last30days/.env && chmod 600 ~/.config/last30days/.env`. Saved briefs go to `~/Documents/Last30Days` unless `LAST30DAYS_MEMORY_DIR` is set.
8. Per project: nothing. It is on everywhere in Claude.
9. Verify: `claude plugin list` shows `last30days@last30days-skill` enabled at the newest tag; `ai-doctor` shows "Claude plugin last30days installed and on" and no "update available: last30days"; no `/last30days:` status line at session start (v3.39.0 and later); `/last30days <topic>` runs the engine (Bash `scripts/last30days.py`).
10. Cleanup: `claude plugin uninstall last30days@last30days-skill`, `claude plugin marketplace remove last30days-skill`; delete `~/.config/last30days/`, `~/Documents/Last30Days/` (or `LAST30DAYS_MEMORY_DIR`) and any `.claude/last30days.env` in projects; remove `last30days-*` Keychain items if the wizard made them.
